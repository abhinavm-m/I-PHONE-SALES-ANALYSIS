# 📱 iPhone Sales Analysis Dashboard

An interactive **iPhone Sales Analysis Dashboard** created using Excel to analyze sales performance, product trends, revenue, and other key business insights.

## 📊 Dashboard Preview

![iPhone Sales Analysis Dashboard](./iphone-sales-dashboard.png)

## 🔍 Project Overview

This project focuses on analyzing iPhone sales data to identify important sales trends and business insights through an interactive dashboard.

The dashboard provides a clear visual representation of sales performance and helps understand product-wise and overall sales patterns.

## 🎯 Objectives

- Analyze overall iPhone sales performance
- Identify top-performing products
- Understand sales trends
- Compare product performance
- Generate meaningful business insights
- Present findings through an interactive dashboard

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Analysis

## 📈 Key Dashboard Features

- Sales performance analysis
- Product-wise analysis
- Interactive charts
- KPI metrics
- Sales trend visualization
- Data-driven insights
